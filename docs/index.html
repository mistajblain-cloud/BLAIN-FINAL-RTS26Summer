SKIF-A7 SECURITY

Real-Time Systems Final Capstone

Joshua Blain • University of Central Florida

Project Overview

SKIF-A7 Security is an embedded security monitoring system developed on an ESP32 using FreeRTOS. The project demonstrates real-time scheduling, interrupt handling, task synchronization, and deterministic software design through a simulated security application.

The system includes four periodic tasks responsible for tamper detection, vibration analysis, integrity verification using CRC-32, and event prioritization. A GPIO interrupt uses a Direct Task Notification to wake a high-priority bottom-half task while a mutex protects the shared security state from race conditions.
